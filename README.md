4. Abstract    

The Grade and Attendance Tracker is a Java-based application designed to provide a simple and organized solution for managing student academic information. The system helps maintain important student details such as student ID, name, marks, and attendance records. It automates the calculation of attendance percentages and grades, making the process faster and reducing errors that may occur during manual calculations.

The application uses various Java programming concepts, including variables, data types, operators, conditional statements, loops, classes, objects, and methods to process and manage student information. Based on the marks entered, the system can determine the corresponding grade, while attendance records can be used to calculate the student's attendance percentage and identify attendance requirements.

The main purpose of this project is to make student performance tracking more efficient, accurate, and easy to manage. It provides a structured way to view academic performance and attendance in one system. The project also demonstrates how fundamental Java programming concepts can be applied to solve a practical real-world problem in an educational environment.
